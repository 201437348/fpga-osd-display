# 亮度/对比度调节 与 全部按键 使用手册

日期：2026-09-23。适用工程：`fpga/osd_display`（康芯 HX4S20C / 安路 EG4S20BG256，
HDMI 640×480@60Hz）。本文只讲**上板怎么操作**，不讲 RTL 实现。

---

## 第一部分：硬件与信号速查

| 器件 | 引脚 | 有效电平 | 功能 | 消抖 |
| --- | --- | --- | --- | --- |
| **KEY1** | B2 | 按下 = 0 | 手动切到下一张图 | 50 ms |
| **KEY2** | C1 | 按下 = 0 | 自动轮播 开 / 关 | 50 ms |
| **KEY3** | B1 | 按下 = 0 | 亮度/对比度：短按 +步长，长按 −步长 | 20 ms |
| **SW1** | C8 | **拨上 = 1** | 通道选择 bit0 | 10 ms 采样 |
| **SW2** | C7 | **拨上 = 1** | 通道选择 bit1 | 10 ms 采样 |
| **SW3** | C6 | **拨上 = 1** | 步长选择 bit0 | 10 ms 采样 |
| **SW4** | C5 | **拨上 = 1** | 步长选择 bit1 | 10 ms 采样 |

## 第二部分：全部按键功能（详细）

### 2.1 KEY1 —— 手动下一张

- **操作**：按一下（按下即触发，不需要长按）。
- **生效条件**（三个都满足才动作）：
  1. 图片管理器**空闲**（`manager_idle`）；
  2. **没有转场动画在跑**（`transition_busy` = 0）；
  3. 已扫描到**至少 1 张**图。
- **效果**：切到下一张图（带既有的滑动/淡入转场），到末尾后回绕到第一张。
- **注意**：条件不满足时这次按键**直接丢弃，不排队**。也就是说在加载中或
  转场过程中连按 KEY1 是无效的，要等画面稳定后再按。
- **副作用**：按 KEY1 会把**自动轮播的 1 秒计时清零**——如果自动轮播正开着，
  手动切一张后，下一次自动切换会从这一刻重新数 1 秒。

### 2.2 KEY2 —— 自动轮播 开 / 关

- **操作**：按一下切换一次（开 → 关 → 开 …）。
- **生效条件**：**图片数必须 > 1**。只有 1 张图时按 KEY2 **完全没反应**
  （这是刻意的，1 张图轮播没意义）。
- **轮播间隔**：**1 秒**（`AUTO_INTERVAL_SECONDS = 1`），即每约 1 秒自动切下一张
  （实际间隔还要加上转场动画的时间，观感约 1.5 秒一张）。
- **计时条件**：只有画面有效、管理器空闲、图片数 > 1 时才计时；加载/转场期间
  计时暂停，不会"欠账"连切两张。
- **副作用**：按 KEY2 同样会把计时清零。
- **⚠️ 没有屏幕指示**：状态栏不显示自动轮播的开/关状态。
  **判断方法**：手不要碰按键，看画面是否每 1~1.5 秒自己换一张。
  想确认是"关掉了"还是"卡住了"，按一下 KEY1——能立刻切图说明系统正常，
  只是自动轮播处于关闭状态。

### 2.3 KEY3 —— 亮度 / 对比度（本文重点，见第三部分）

- **短按**（按下后 1 秒内松手）：当前通道 **+ 步长**。
- **长按**（按住 ≥ 1 秒再松手）：当前通道 **− 步长**。
- **只在松手那一刻判定一次**：按住 1 秒不会"按住时先减一次、松手又减一次"。
- **调哪个通道、步长多大**，由 SW1~SW4 决定（见第三部分）。
- **当 SW1、SW2 都拨上（= 恢复默认档）时，KEY3 无效**——这一档是持续强制
  恢复默认值，按 KEY3 不做任何事。
- KEY3 与 KEY1/KEY2 **完全独立**：调亮度不会切图，也不受转场/加载影响，
  任何时候都能调。

### 2.4 按键之间的关系

| 组合 | 行为 |
| --- | --- |
| KEY1 + 自动轮播开着 | 手动切一张，并把自动计时重置为 1 秒 |
| KEY2 + 只有 1 张图 | 无反应 |
| KEY1/KEY2 + 正在转场 | 无反应（按键被丢弃） |
| KEY3 + 任何状态 | 始终可用（恢复默认档除外） |
| KEY1/KEY2 与 KEY3 同时按 | 互不干扰，各做各的 |

## 第三部分：亮度/对比度 完整操作手册

### 3.1 原理一句话

图片像素经过一条流水线：**亮度**先按 `x*(b+1)/256` 缩放，**对比度**再以 128
为中心做 `sat(floor((bright−128)*c/128)+128)` 拉伸。两个参数都是 8 位（0~255）。

- **亮度 255、对比度 128** 时是**逐位恒等旁路**——画面和不开这功能一模一样。
- **只影响图片本身**。OSD 的顶部标题栏、底部状态栏、滚动字幕、右上角参数菜单、
  底部音频柱**全部保持全亮**，不受影响。
- 参数在**帧边界（vs）生效**，所以调的时候不会出现"上半屏旧值、下半屏新值"。

### 3.2 两个参数的实际手感

| 参数 | 默认 | 范围 | 调大的效果 | 调小的效果 | 注意 |
| --- | --- | --- | --- | --- | --- |
| **亮度 B** | **255** | 0~255 | 变亮 | 变暗，到 0 时图片**全黑**（OSD 仍在） | **默认已经是最大值**，所以亮度只能往下调暗，不能更亮 |
| **对比度 C** | **128** | 0~255 | 反差变大、暗部更黑亮部更白 | 反差变小，趋近灰蒙蒙 | 默认在中间，可上可下 |

> ⚠️ **最容易误解的一点**：亮度默认 255 = 最亮。所以"想调亮一点"是**做不到**的，
> 你只能把图片调暗。如果你的图片本身偏暗，请调**对比度**或换图，
> 不要指望亮度。

### 3.3 SW1 / SW2 —— 决定"调哪个"（拨上 = 1）

| SW1 | SW2 | 通道 | 菜单表现 |
| --- | --- | --- | --- |
| 拨下 (0) | 拨下 (0) | **只调亮度** | B 行黄色高亮，C 行暗蓝 |
| **拨上 (1)** | 拨下 (0) | **只调对比度** | B 行暗蓝，C 行黄色高亮 |
| 拨下 (0) | **拨上 (1)** | **两个一起调** | B、C 两行**都**黄色高亮 |
| 拨上 (1) | 拨上 (1) | **恢复默认** | 两行都高亮，数值被持续强制为 255 / 128 |

### 3.4 SW3 / SW4 —— 决定"一次变多少"（拨上 = 1）

| SW3 | SW4 | 步长 | 适合 |
| --- | --- | --- | --- |
| 拨下 (0) | 拨下 (0) | **1** | 精细微调 |
| **拨上 (1)** | 拨下 (0) | **4** | 小步调整 |
| 拨下 (0) | **拨上 (1)** | **16** | 常规调整（推荐先用这个） |
| 拨上 (1) | 拨上 (1) | **32** | 快速大范围拉 |

**四个档位全部有实际作用，没有"保留档"。** 这是刻意改的：早期版本把 `11`
当成保留，结果"四个开关全拨上"这个最自然的位置按 KEY3 没反应，
上板时被误判成功能坏了。

### 3.5 右上角菜单面板长什么样

- **位置**：屏幕**右上角**，横向 `x = 448~632`（宽 184 px），纵向 `y = 24~60`
  （高 36 px），深色面板 `#0B1526`。
- **两行**：
  - 上行 **`B`** = 亮度（`y ≈ 26`）
  - 下行 **`C`** = 对比度（`y ≈ 44`）
- **每行内容**（从左到右）：
  1. 一个字母标签 `B` / `C`；
  2. **3 位十进制数值**（0~255）。小于 100 时百位显示为**空白**，
     所以 128 显示成 ` 128`、42 显示成 `  42`；
  3. 一条 **8 段进度条**，每段代表 32：第 i 段在数值 > i×32 时点亮。
     所以 255 全亮（8 段）、128 亮 4 段、0 全灭。
  - 进度条颜色：当前通道的已填充段是**亮青** `#54E3E3`；"一起调"时
    非当前通道的已填充段暗一档 `#2E6E6E`；未填充段 `#10213A`。
- **字母颜色**：黄色 `#FFD166` = 当前在调的通道；暗蓝 `#A7C7FF` = 没在调的。
- **自动隐藏**：**最后一次操作后 5 秒**菜单消失。再动开关或按 KEY3 会重新计时。
  菜单消失不影响已生效的参数值。

### 3.6 操作步骤（照做即可）

#### 场景 A：把图片调暗一点（步长 16，每次 −16）

1. SW1 **拨下**、SW2 **拨下** → 通道 = 只调亮度。
2. SW3 **拨下**、SW4 **拨上** → 步长 = 16。
3. 长按 **KEY3** 超过 1 秒，然后松手 → 亮度 255 → **239**。
4. 想继续调暗就重复第 3 步：239 → 223 → 207 …
5. 右上角菜单会出现，B 行数值和进度条同步变化；5 秒后自动消失。

> 想让亮度**回到 255**：按 3.7 的"恢复默认"，或用 SW1/SW2 拨到"只调亮度"
> 后**短按** KEY3 若干次加回去（每按一次 +16）。

#### 场景 B：提高对比度（每次 +16）

1. SW1 **拨上**、SW2 **拨下** → 通道 = 只调对比度。
2. SW3 **拨下**、SW4 **拨上** → 步长 = 16。
3. **短按** KEY3 → 对比度 128 → **144**。
4. 重复短按：144 → 160 → 176 … 到 255 就封顶不再变。

#### 场景 C：降低对比度（每次 −16）

1. SW1 **拨上**、SW2 **拨下** → 通道 = 只调对比度。
2. SW3 **拨下**、SW4 **拨上** → 步长 = 16。
3. **长按** KEY3 超过 1 秒再松手 → 128 → **112**。
4. 重复：112 → 96 → 80 … 到 0 就到底不再变。

#### 场景 D：亮度和对比度一起微调（步长 1）

1. SW1 **拨下**、SW2 **拨上** → 通道 = 两个一起调。
2. SW3 **拨下**、SW4 **拨下** → 步长 = 1。
3. **短按** KEY3 → 亮度 −1（往下调）同时对比度 +1。每按一次都同时动两个值。
4. 菜单里 B、C 两行都是黄色高亮。

> 注意"一起调"时两个值**同向加/减**：短按是都 +1，长按是都 −1。
> 亮度默认 255 已在顶，所以短按只会把对比度推上去。

#### 场景 E：一键恢复默认（亮度 255 / 对比度 128）

1. SW1 **拨上**、SW2 **拨上** → 进入"恢复默认"档。
2. **立刻**生效：亮度和对比度被**持续强制**为默认值，画面恢复正常。
3. 把 SW1 或 SW2 拨回下面，就退出这一档，之后从默认值继续调。
4. 这一档下 **KEY3 没有任何作用**（不需要按）。

#### 场景 F：快速大范围试效果

1. SW3 **拨上**、SW4 **拨上** → 步长 = 32。
2. 用 SW1/SW2 选通道，短按/长按 KEY3 几下就能拉到位。
3. 试出合适的观感后，再把 SW3/SW4 拨到步长 1 或 4 精调。

### 3.7 重要规则与陷阱（务必看一遍）

1. **数值两端饱和，不会回绕**。255 再加还是 255，0 再减还是 0。
   （早期版本会回绕，255+1 变 0 直接把屏幕搞黑，已修掉。）
2. **恢复默认档是"持续强制"**：只要 SW1、SW2 都拨上，参数就一直被压在默认值。
   所以别把两个开关长期留在"都拨上"的位置，否则你调好的值会被一直覆盖。
3. **一次长按只减一次**：长按的判定在**松手那一刻**。按住不放不会连续减。
4. **步长改变立即生效**，不需要重新上电。
5. **通道改变立即生效**，菜单高亮同步变化。
6. **菜单 5 秒自动消失**是正常的，参数不会跟着丢。
7. **亮度调到 0 图片全黑是预期行为**，OSD 文字和音频柱仍然可见——
   这可以当作"确认 OSD 层独立于图片层"的演示。
8. **只调图片**：字幕、标题、状态栏、音频柱、参数菜单都不受影响。
9. **参数在帧边界生效**，所以调节时画面不会撕裂。
10. **参数不写 Flash**：断电或按 RST_N 复位后回到默认（亮度 255 / 对比度 128）。
11. **四个拨码开关都参与**，不存在"无效档"。
12. **拨码有 10 ms 消抖**，切换时不会因为机械抖动乱跳数值。

### 3.8 排查表

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 按 KEY3 完全没反应，菜单也不出现 | SW1、SW2 都在"拨上"位置（恢复默认档，KEY3 被设计为无效） | 把 SW1 或 SW2 拨下 |
| 按 KEY3 有反应，但亮的是 C 行而不是 B 行 | 拨码极性与预期相反（板上开关方向理解反了） | 按第 5 节自检，把"拨上/拨下"对调理解 |
| 数值变了一下又跳回 255/128 | SW1、SW2 停在"都拨上"的恢复默认档 | 拨下其中一个开关 |
| 怎么按都不会变亮 | 亮度默认已经是 255（最大），只能调暗 | 改调对比度，或换更亮的图 |
| 菜单不显示但画面确实变了 | 菜单只在最后一次操作后 5 秒内显示 | 正常现象；再按一下 KEY3 就会重新出现 |
| 调完后画面上下半屏颜色不一样 | 不应发生（参数在帧边界提交） | 属异常，记录并按第 5 节核对极性 |
| 图片全黑，但能看到字幕和状态栏 | 亮度被调到 0 | 用恢复默认档，或短按 KEY3 加回来 |
| 断电后设置丢了 | 参数不持久化（设计如此） | 需要每次上电重调；如需持久化要另做需求 |

## 第五部分：拨码极性 10 秒自检

因为代码注释里对极性有三种互相矛盾的说法，上板第一件事先做这个自检：

1. 把 **SW1、SW2、SW3、SW4 全部拨下**（预期：只调亮度、步长 1）。
2. **短按 KEY3 一次**。
3. 看右上角菜单：
   - **B 行黄色高亮，且 B 的数值变成 254** → 极性正确，按本文档操作。
   - **C 行黄色高亮** → 极性相反：把本文档里所有"拨上"读成"拨下"、
     "拨下"读成"拨上"。
4. 自检完用 **SW1、SW2 都拨上** 恢复默认（255 / 128）。

> 不符，建议让写这块的人改成与 `top.v` 一致的说明，免得下次上板又搞混。
