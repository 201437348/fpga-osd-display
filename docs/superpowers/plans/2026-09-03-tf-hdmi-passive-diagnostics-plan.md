# TF-HDMI 被动诊断实施计划

日期：2026-09-03

## 范围

实现已批准的六位数码管被动诊断，不改变图片加载、SDRAM、HDMI、按键和 1 秒超时的控制行为。

## 步骤

1. 在 `sd_card_bmp.v` 增加 8 位只读诊断输出：3 位图片计数和 5 个粘滞事件。
2. 在现有事件发生位置旁路锁存首图加载、源结束、写完成、显示提交和加载超时。
3. 在 `top_tf_hdmi_audio.v` 增加六路十六进制译码，按左到右 `S C L R W X` 接入现有扫描器。
4. 添加 Icarus Verilog 测试平台，验证复位、事件保持、提交结果和超时优先级。
5. 运行语法/行为测试和差异检查，确认没有修改业务条件。
6. 保留基线构建信息，随后由用户在 TD 中重新运行综合和布局布线。
7. 使用 JTAG 临时下载诊断 bit，记录六位稳定结果并更新项目路线图。

## 完成条件

- Icarus Verilog 测试通过；
- TD 综合无新增 HDL 错误或关键警告；
- 六位数码管能给出可按设计文档判读的稳定结果。
