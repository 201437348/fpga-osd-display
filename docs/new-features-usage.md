# 新增功能使用说明：图片缩放、亮度/对比度菜单

日期：2026-09-23。适用工程：`fpga/osd_display`（EG4S20BG256，640×480@60Hz）。
本文件说明工作区里两块**不是你自己写**的新功能怎么用。

---

## 0. 先澄清一件事：工程里没有"缩略图"

我在整个仓库（RTL、测试、文档、工具脚本）里搜过 `thumbnail` / `缩略`，
**一处都没有**。本次新增的第三块功能是**图片缩放（双线性插值）**：

- `rtl/image/image_bilinear_scaler.v`（新增，36 KB）
- `rtl/storage/fat32_bmp_loader.v`（扩展：输出源宽高、放宽尺寸限制）
- `rtl/storage/image_storage_adapter.v`（数据通路改成
  `fat32_bmp_loader → image_bilinear_scaler → write_buf → SDRAM`）

它让**任意分辨率的 BMP 缩/放到 640×480 显示**——大照片被缩小铺满屏幕，
所以很可能就是你说的"缩略图"。下面按这个理解写；如果你指的是别的东西，
告诉我我再补。

## 1. 图片缩放怎么用

### 1.1 什么样的图能被接受

| 条件 | 值 | 说明 |
| --- | --- | --- |
| 格式 | BMP | 按 `BM` 头识别 |
| 位深 | **24 bpp** | 其它位深拒绝 |
| 压缩 | **无压缩**（`biCompression == 0`） | RLE 等一律拒绝 |
| 宽 | 1 .. **1920** | `MAX_SRC_WIDTH` |
| 高 | 1 .. **1080**，且必须为正 | top-down（负高度）BMP 会被拒绝 |
| 像素总数 | **≥ 32000**（约 179×179） | `MIN_SRC_PIXELS`，太小会被拒 |

不满足条件的图会走原有的回退路径（彩条 + 状态栏提示），不会黑屏。

### 1.2 显示效果

- 输出**恒为 640×480**，缩放后直接铺满整屏。
- **不保持宽高比、不加黑边**：X、Y 各自独立映射（`sx = i*srcW/640`，
  `sy = j*srcH/480`）。所以 16:9 的照片（如 1920×1080）会被**纵向拉长**成 4:3。
  想不变形，请把图预先裁成 4:3 再放卡。
- 缩放是**双线性插值**（不是最近邻），比原来的硬缩放平滑。

### 1.3 怎么放图

- 工程走的是**真正的 FAT32 根目录枚举**（`fat32_directory_scan`），
  不是按物理扇区盲扫。文件数据按 **FAT 簇链**读取
  （`fat32_file_sector_reader`，`MAX_FILE_CLUSTERS = 0xFFFF`），
  所以**文件碎片化不影响**，也没有"必须在前 64 MiB 内"的限制。
- **文件名必须是 8.3 短名且扩展名为 `BMP`**（匹配条件为短名最后三字节
  等于 `'B''M''P'`）。Windows 创建的长文件名会生成大写 8.3 别名，
  一般能匹配；但最稳妥是直接命名成 `A1.BMP` … `A8.BMP`。
- 只扫描**根目录**（`MAX_ROOT_DIR_CLUSTERS = 64`）。
- 图片数量上限从 4 张提高到 **8 张**（`SCAN_TARGET_COUNT = 8`，
  索引位宽同步从 2 位扩到 3 位）；取目录顺序里的前 8 个。
- 音频文件必须严格命名为 `BGM.WAV`。
- 换图/轮播仍用原来的按键，行为不变。

## 2. 亮度/对比度菜单怎么用

> **完整版见 [亮度/对比度调节与全部按键使用手册](brightness-contrast-and-keys-guide.md)**
> （含 KEY1/KEY2/KEY3 全部按键行为、逐步操作场景、陷阱与排查表）。
> 下面只保留速查内容。

### 2.1 硬件

| 器件 | 引脚 | 作用 |
| --- | --- | --- |
| KEY1 | B2 | 手动下一张（原有） |
| KEY2 | C1 | 自动播放 开/关（原有） |
| **KEY3** | **B1** | **亮度/对比度：短按 +步长，长按 −步长** |
| **SW1** | **C8** | 通道选择 bit0 |
| **SW2** | **C7** | 通道选择 bit1 |
| **SW3** | **C6** | 步长选择 bit0 |
| **SW4** | **C5** | 步长选择 bit1 |

### 2.2 拨码开关设置（**拨上 = 1**）

**SW1 / SW2 —— 调哪个参数：**

| SW1 | SW2 | 通道 |
| --- | --- | --- |
| 拨下 (0) | 拨下 (0) | 只调**亮度** |
| **拨上 (1)** | 拨下 (0) | 只调**对比度** |
| 拨下 (0) | **拨上 (1)** | 亮度和对比度**一起调** |
| 拨上 (1) | 拨上 (1) | **恢复默认**（持续生效） |

**SW3 / SW4 —— 一次按 KEY3 变化多少：**

| SW3 | SW4 | 步长 |
| --- | --- | --- |
| 拨下 (0) | 拨下 (0) | 1 |
| **拨上 (1)** | 拨下 (0) | 4 |
| 拨下 (0) | **拨上 (1)** | 16 |
| 拨上 (1) | 拨上 (1) | 32 |

> 四个档位**全部有实际作用**，没有"保留档"。这是刻意改的：早期版本把
> `11` 当成保留、按 KEY3 没反应，上板时被误判成功能坏了。

### 2.3 按键

- **短按 KEY3（< 1 秒）**：当前通道 **+ 步长**。
- **长按 KEY3（≥ 1 秒）再松手**：当前通道 **− 步长**。
  长按只在**松手那一刻**判定一次，不会按住期间先减一次、松手再减一次。
- 数值两端**饱和钳位**在 0..255，不会回绕（不会 255+1 变 0 把屏幕搞黑）。

### 2.4 屏幕上的菜单

- 位置：**右上角**，`x = 448..632`，`y = 24..60` 的小面板。
- 两行：上行 **B**（亮度，y=26），下行 **C**（对比度，y=44）。
- 每行显示：**3 位十进制数值**（0..255）+ 一条 **8 段进度条**
  （每段 32，第 i 段在值 > i×32 时点亮）。
- 当前通道的字母是**黄色** `#FFD166`，另一个是**暗蓝** `#A7C7FF`。
- 菜单在**最后一次操作后 5 秒**自动消失；再操作会重新计时。
- 参数在**帧边界（vs）**提交，所以调节时不会出现"上半帧旧值、下半帧新值"的撕裂。

### 2.5 默认值与影响范围

- 默认：**亮度 255、对比度 128** → 此时是**逐位恒等旁路**（画面和不开这功能完全一样）。
- 公式：亮度 `out = x*(b+1)/256`；对比度 `sat(floor((bright-128)*c/128)+128)`。
- 只作用于**图片本身**。OSD 的标题栏、状态栏、滚动字幕、参数菜单、音频柱
  都**保持全亮**，不受亮度/对比度影响。
- 亮度调到 0 → 图片全黑（OSD 仍在）。

## 3. 一个要注意的文档不一致（极性）

代码里三处注释互相矛盾，实际以代码为准：

| 位置 | 说法 |
| --- | --- |
| `constraints/pin.adc` | "全部 PULLUP => 低有效（按下/合上 = 0）" |
| `param_menu_controller.v` 头部 | "sw 低有效（合上 = 0）；顶层已取反" |
| `top.v` 第 446-458 行 | "拨上为 1，拨下为 0，**不做取反**；早期按 PULLUP 推断成合上=0 并取反，方向与手册相反，已修正" |

**代码实际行为**：`top.v` 里是 `wire [3:0] sw_act = sw;`，**没有取反**，
所以按 `top.v` 的注释：**拨上 = 1**。`param_menu_controller.v` 的头部注释是
过期的（描述的是旧行为），建议顺手改掉。

**10 秒自检方法**：四个开关**全部拨下**，按一下 KEY3。
- 菜单上行 **B** 的数值 +1 → 极性正确，按第 2.2 节用。
- 如果亮的是 **C** 行（对比度）→ 极性相反，把"拨上/拨下"对调理解。

## 4. 顺带：数码管诊断位（本次一起加的）

`top.v` 在**加载/校验期间**（`load_in_progress`）借用了 C/L/W 三位显示诊断值，
正常显示时含义不变：

| 位 | 加载期间 | 平时 |
| --- | --- | --- |
| C | `fat32_bmp_loader` 状态码（5 = 等 `write_req_ack`，8 = 正常收数据，9 = 被反压挂住） | 图片数量 |
| L | 已读完扇区数的低 4 位（在跳 = 有进度，冻结 = 卡死） | 加载中标志 |
| W | `{write_req_ack, Sdr_init_done, 缩放器 out_stall, 缩放器输入 FIFO afull}` | 写完成标志 |

排查"某张图加载不动"时，看 L 位是否还在跳是最快的判断方法。
